# 4.4 Implementasi Sistem

Implementasi sistem merupakan tahapan krusial dalam siklus pengembangan perangkat lunak yang mentransformasikan rancangan model *use case*, perancangan diagram aktivitas, serta struktur basis data yang telah dibahas pada sub-bab sebelumnya ke dalam bentuk program aplikasi yang utuh dan dapat dioperasikan. Pada sub-bab ini diuraikan spesifikasi lingkungan implementasi (perangkat keras dan lunak), implementasi antarmuka pengguna (*User Interface*) pada setiap modul sistem, serta implementasi logika kode program kunci yang mendukung proses bisnis.

## 4.4.3 Implementasi Logika dan Kode Program Kunci

Di samping tampilan visual antarmuka, sistem ini didukung oleh logika backend yang menjamin kelancaran transaksi data medis dan keamanan proses operasional. Beberapa implementasi algoritma dan kode program penting diuraikan sebagai berikut:

### 1. Logika Penomoran Antrean Otomatis dan Validasi Kuota
Untuk memastikan nomor urut antrean akseptor bertambah secara sekuensial tanpa ada nomor yang terlewat atau duplikat pada satu sesi pelayanan yang sama, sistem menggunakan transaksi database atomik yang mengunci sesi jadwal serta memeriksa batas kuota sebelum nomor antrean diterbitkan.

```php
// Potongan kode penomoran antrean otomatis pada RegistrasiMandiri.php
DB::transaction(function () use ($jadwal) {
    // Kunci record jadwal untuk mencegah race condition
    $jadwalAktif = JadwalPelayanan::lockForUpdate()->findOrFail($this->jadwal_pelayanan_id);

    // Hitung antrean yang sudah terdaftar
    $totalPendaftar = AntrianJadwal::where('jadwal_pelayanan_id', $jadwalAktif->id)->count();

    if ($totalPendaftar >= $jadwalAktif->kuota) {
        throw new \Exception('Mohon maaf, kuota antrean untuk jadwal ini sudah penuh.');
    }

    $nomorAntrianBaru = $totalPendaftar + 1;

    $antrian = AntrianJadwal::create([
        'jadwal_pelayanan_id' => $jadwalAktif->id,
        'peserta_kb_id'       => $this->peserta_kb_id,
        'nomor_antrian'       => $nomorAntrianBaru,
        'status'              => 'terdaftar',
    ]);
});
```

### 2. Logika Alur Wizard Pelayanan Tiga Tahap (Livewire Multi-Step Wizard)
Proses pelayanan medis KB membutuhkan runtutan langkah yang terstruktur, dimulai dari skrining klinis, persetujuan medis, hingga input alokon dan kunjungan ulang. Livewire mengelola navigasi langkah (step), validasi bertahap, serta persistensi data antar-langkah.

```php
// Potongan kontrol wizard pada Pelayanan/Create.php
public int $currentStep = 1;

public function nextStep(): void
{
    if ($this->currentStep === 1) {
        $this->validateSkriningMedis();
    } elseif ($this->currentStep === 2) {
        $this->validateInformedConsent();
    }
    $this->currentStep++;
}

public function previousStep(): void
{
    if ($this->currentStep > 1) {
        $this->currentStep--;
    }
}
```
